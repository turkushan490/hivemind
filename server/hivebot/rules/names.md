# Names

Who answers. The name can be anywhere in the first 5 words ("okay Jev", "hey Jarvis, ..."). Each line is
`- <what speech-to-text heard> → <character>`. Add a line when a name is misheard; the robot and the browser get it at
their next config check, no firmware update needed.

When no name is heard: see `listening.md` (default character and the follow-up window).

## Word starts
A word of this length that starts like this is that character too ("ultrono", "jarvisz").
- ultr*, altr*, oltr* (5-9 letters) → ultron
- jarv* (5-8 letters) → jarvis
- visio* (6-8 letters) → vision
