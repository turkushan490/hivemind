# Unlock mode

Unlock mode is a **private area behind a PIN**. It keeps chosen memory, workflows, skills and files out of the normal views; they only show while you are unlocked.

## Set it up

1. Go to **Settings → Unlock PIN** and choose a PIN (4–32 characters).
2. A small lock appears in the top menu. Click it and type your PIN to unlock.
3. Choose when it locks again by itself: after **1 hour**, **12 hours** (the default), **1 day**, or **never**.

## What shows while unlocked

- **Memory → Hidden:** your hidden memory files.
- **Hidden workflows** in *Open…*. Their runs stay hidden too.
- **Locked skills** on the Skills page. Only hidden workflows use them.
- An **Unlocked** section on the Files page. You can lock or unlock your own files by hand.

When it locks, all of this is out of view again. Nothing is deleted.

## Who can use it

Admins and users, each with their own PIN. Viewers and API tokens can't unlock.

> Unlock mode hides things inside the app. It is not encryption: anyone who can read the server's data folder can read the data. Keep `/data` and its backups safe.
